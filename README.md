# Куда пойти

Сайт с картой интересных мест Москвы

## Что представляет из себя проект?

- Карта с точками всех мест 
- Сайдбар с фотографиями и описанием при клике по точке.
- Админка: добавление мест, загрузка фото, drag-n-drop для сортировки.
- Management-команда: загрузка мест из JSON по URL.

## Переменные окружения 

- `DEBUG` = Это переменная откладки. Она нужна чтобы видеть ошибки от нашего проекта
- `SECRET_KEY` = Это секретный ключ от проекта.
- `ALLOWED_HOSTS` = настройка, которая определяет список доменов и IP-адресов, которым разрешено обслуживать ваш сайт

Откройте файл .env, и запишите свои данные в переменные в таком формате: `SECRET_KEY = Ваш_Ключ`
