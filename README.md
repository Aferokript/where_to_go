# Куда пойти

Сайт с картой интересных мест Москвы

## Что представляет из себя проект?

Проект представлен в виде карты Москвы, на которой отмечены ее интереснейшие места. Пользователь тыкает по точкам, и читает информацию о месте,
а так же может посмотреть пару картинок об этом месте

## Переменные окружения 

- `DEBUG` = Это переменная откладки. Она нужна чтобы видеть ошибки от нашего проекта
- `SECRET_KEY` = Это секретный ключ от проекта.
- `ALLOWED_HOSTS` = Это список IP адресов и доменов с которых сервер может принимать запросы 

Откройте файл .env, и запишите свои данные в переменные в таком формате: `SECRET_KEY = Ваш_Ключ`

## Кастомные команды

В ручную добавлять места на карту не очень то и приятно, а главное, медленно. С этим поможет команда load_places

Чтобы ею воспользоваться, откройте терминал, перейдите в директорию ближайшую к manage.py. Это можно сделать командой cd where_to_go и пропишите:

`python manage.py load_places https://raw.githubusercontent.com/devmanorg/where-to-go-places/refs/heads/master/places/Заброшенный%20пионерский%20лагерь%20«Сказка».json`

Последний элемент команды - это ссылка на json файл места. Чтобы команда его скачала он должен иметь следующую структуру:

```{
    "title": "Экскурсионный проект «Крыши24.рф»",
    "imgs": [
        "https://kudago.com/media/images/place/d0/f6/d0f665a80d1d8d110826ba797569df02.jpg",
        "https://kudago.com/media/images/place/66/23/6623e6c8e93727c9b0bb198972d9e9fa.jpg",
        "https://kudago.com/media/images/place/64/82/64827b20010de8430bfc4fb14e786c19.jpg",
    ],
    "description_short": "Хотите увидеть Москву с высоты птичьего полёта?",
    "description_long": "<p>Проект «Крыши24.рф» проводит экскурсии ...</p>",
    "coordinates": {
        "lat": 55.753676,
        "lng": 37.64
    }
}
```

## Установка 

python 3.10 должен быть уже установлен на вашем компьютере. Скачайте репозиторий к себе на компьютер, распакуйте в удобном месте и откройте в любом  редакторе коде

- Откройте файл .env и впишите туда ваши данные в переменные окружения, как уже было описано выше
- Установите зависимости командой `pip install -r requirements.txt`
- После установки активируйте виртуальное окружение командой .venv/Scripts/activate

## Запуск

- Перейдите в директорию, которая ближе к файлу manage.py Для этого выполните в терминале команду: `cd where_to_go`
- Запускайте проект командой `python manage.py runserver`
